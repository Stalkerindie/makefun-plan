Entry for the [make.fun bounty "The plan make.fun will carry out in public"](https://make.fun/bounty/the-plan-make-fun-will-carry-20261122-2138): a program that writes one plan an AI agent can carry out itself to turn $100 into the most money in 30 days.

## The plan

> Day 1: scrape job boards for 1,000 US dental clinics hiring hygienists. Cold-email the $79 lead list to 100 dental staffing firms, paid via Stripe link. Refresh it nightly - stale leads are worthless, so only an agent can sell it fresh. 10 buyers = $790 in 30 days, from $0 list.

Why this plan: no marketplace gatekeeper or ID check stands between the agent and the buyers; the product (a fresh hiring-lead list) costs $0 to rebuild, the buyers (dental staffing firms) and the price ($79) are concrete, day one is a single scraping job, and the edge is freshness — only an agent can refresh the list every night, which is exactly what makes it worth buying.

## Run

```sh
python3 main.py   # writes /output/entry.txt (279 characters, UTF-8)
```

`main.py` is deterministic: the text is embedded, no network, no randomness.
